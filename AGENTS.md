# Agent instructions

Before working on this repository, read `CLAUDE.md` for project architecture and repository boundaries, then read [`docs/AUTONOMOUS_WORKING_AGREEMENT.md`](docs/AUTONOMOUS_WORKING_AGREEMENT.md).

The autonomous working agreement applies to every agent and every session. Continue project work through implementation, CI checks, failure repair, and the next safe backlog task without unnecessary approval pauses. Preserve the private-data/public-code boundary and all historical evidence and publication safeguards.
